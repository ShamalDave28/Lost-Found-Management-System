# Lost & Found Management System

A DBMS-based web application developed using PHP and MySQL for reporting, tracking, and managing lost and found items.

## Features
- User Registration & Login
- Add Lost/Found Items
- Search Items
- View Item Details
- Delete Records
- MySQL Database Integration

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Database
Import the `db.sql` file into phpMyAdmin.

## How to Run
1. Install XAMPP
2. Place project folder inside `htdocs`
3. Start Apache & MySQL
4. Import `db.sql`
5. Open localhost/project-folder-name
